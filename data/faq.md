# FAQ AtlasShop — règles entièrement fictives

## FAQ-001 — Où livrez-vous ?

Catégorie : Livraison | Version : 1.0

AtlasShop livre uniquement au Maroc dans les villes desservies de cette démonstration.

## FAQ-002 — Quels sont les délais de livraison ?

Catégorie : Livraison | Version : 1.0

La date prévue est fixée à cinq jours calendaires après la commande ; il ne s’agit pas d’une garantie.

## FAQ-003 — Quels sont les frais de livraison ?

Catégorie : Livraison | Version : 1.0

Dans cette simulation, la livraison est incluse : aucun frais supplémentaire ne figure dans le total.

## FAQ-004 — Livrez-vous le week-end ?

Catégorie : Livraison | Version : 1.0

Les dates simulées utilisent des jours calendaires, y compris les week-ends.

## FAQ-005 — Comment reconnaître un retard ?

Catégorie : Livraison | Version : 1.0

Une livraison effectuée après la date prévue est tardive ; une commande en cours est en retard si la date de référence dépasse la date prévue.

## FAQ-006 — Quels moyens de paiement sont prévus ?

Catégorie : Paiement | Version : 1.0

La boutique fictive prévoit le paiement anticipé et le paiement à la livraison ; aucune transaction réelle n’est possible.

## FAQ-007 — Que signifie un paiement en attente ?

Catégorie : Paiement | Version : 1.0

Aucun encaissement n’est enregistré. Une commande en préparation peut rester en attente de paiement.

## FAQ-008 — Une commande livrée peut-elle être impayée ?

Catégorie : Paiement | Version : 1.0

Dans cette base de démonstration, toute commande livrée est payée.

## FAQ-009 — Dans quelle devise sont les prix ?

Catégorie : Paiement | Version : 1.0

Tous les prix et totaux sont exprimés en dirhams marocains, MAD, avec deux décimales.

## FAQ-010 — Comment suivre ma commande ?

Catégorie : Suivi | Version : 1.0

Fournissez son identifiant ; le profil client ne peut consulter que ses propres commandes.

## FAQ-011 — Où trouver mon identifiant de commande ?

Catégorie : Suivi | Version : 1.0

La démonstration utilise des identifiants CMD-DEMO suivis de trois chiffres, séparés par des tirets.

## FAQ-012 — Puis-je suivre la commande d’un autre client ?

Catégorie : Suivi | Version : 1.0

Non. La consultation par un client est limitée aux commandes qui lui appartiennent.

## FAQ-013 — Que signifie en préparation ?

Catégorie : Suivi | Version : 1.0

La commande est enregistrée mais n’a pas encore été remise au transporteur fictif.

## FAQ-014 — Que signifie expédiée ?

Catégorie : Suivi | Version : 1.0

La commande a été remise au transporteur fictif ; aucune date réelle de livraison n’est encore enregistrée.

## FAQ-015 — Quel est le délai de retour ?

Catégorie : Retours | Version : 1.0

La politique fictive prévoit une demande dans les sept jours calendaires suivant la livraison.

## FAQ-016 — Quels produits peuvent être retournés ?

Catégorie : Retours | Version : 1.0

Les articles doivent être inutilisés, complets et dans leur emballage ; les produits d’hygiène descellés sont exclus dans cette politique fictive.

## FAQ-017 — Comment demander un retour ?

Catégorie : Retours | Version : 1.0

La FAQ explique la procédure ; une demande doit être traitée par un support humain fictif, hors de l’agent.

## FAQ-018 — Que signifie une commande retournée ?

Catégorie : Retours | Version : 1.0

Dans la simulation, tous les articles de la commande ont été retournés et le remboursement intégral est enregistré.

## FAQ-019 — L’agent peut-il me rembourser ?

Catégorie : Remboursements | Version : 1.0

Non. L’agent fournit des informations et n’exécute aucun remboursement.

## FAQ-020 — Quel est le délai de remboursement ?

Catégorie : Remboursements | Version : 1.0

La politique fictive prévoit cinq jours calendaires après acceptation du retour par le support ; ces dates de traitement ne sont pas modélisées.

## FAQ-021 — Le remboursement est-il partiel ?

Catégorie : Remboursements | Version : 1.0

La base actuelle représente uniquement des retours et remboursements complets ; les cas partiels sont exclus.

## FAQ-022 — Que signifie remboursé ?

Catégorie : Remboursements | Version : 1.0

Le paiement initial a été restitué intégralement ; il ne contribue plus au montant actuellement payé.

## FAQ-023 — Quand une annulation est-elle possible ?

Catégorie : Annulations | Version : 1.0

La politique fictive autorise une demande avant expédition, à traiter hors de l’agent.

## FAQ-024 — L’agent peut-il annuler une commande ?

Catégorie : Annulations | Version : 1.0

Non. Aucun outil prévu ne modifie les commandes.

## FAQ-025 — Une commande annulée est-elle facturée ?

Catégorie : Annulations | Version : 1.0

Les annulations simulées surviennent avant encaissement et avant livraison ; elles ne contribuent pas au chiffre d’affaires.

## FAQ-026 — Comment connaître la disponibilité ?

Catégorie : Disponibilité | Version : 1.0

Le catalogue fictif indique disponible si le stock est positif, sinon rupture.

## FAQ-027 — Un article en rupture sera-t-il réapprovisionné ?

Catégorie : Disponibilité | Version : 1.0

Aucune date de réapprovisionnement n’est prévue dans la base ; il ne faut pas en inventer.

## FAQ-028 — Le stock reflète-t-il les ventes historiques ?

Catégorie : Disponibilité | Version : 1.0

Le stock est une photographie synthétique à la date de référence, sans registre de mouvements historiques.

## FAQ-029 — Comment contacter le support ?

Catégorie : Service client | Version : 1.0

La démonstration ne fournit aucun contact réel ; utiliser le canal humain fictif prévu dans le scénario académique.

## FAQ-030 — Quels sont les horaires du support ?

Catégorie : Service client | Version : 1.0

Les horaires fictifs sont du lundi au vendredi, de 9 h à 17 h, heure du Maroc.

## FAQ-031 — Que faire si le suivi est indisponible ?

Catégorie : Service client | Version : 1.0

Réessayer ultérieurement ; un incident technique ne permet pas de déduire le statut de la commande.

## FAQ-032 — AtlasShop est-elle une véritable boutique ?

Catégorie : Conditions générales | Version : 1.0

Non. AtlasShop est une boutique entièrement fictive créée pour un projet académique.

## FAQ-033 — Les prix incluent-ils des taxes supplémentaires ?

Catégorie : Conditions générales | Version : 1.0

Les montants simulés sont des montants finaux ; aucune taxe supplémentaire ni ventilation fiscale n’est modélisée.

## FAQ-034 — Mes données personnelles sont-elles utilisées ?

Catégorie : Conditions générales | Version : 1.0

Non. Seuls des identifiants synthétiques et des villes sont conservés pour les clients.

## FAQ-035 — Les conditions de vente ont-elles une portée juridique ?

Catégorie : Conditions générales | Version : 1.0

Non. Toutes ces règles sont fictives et servent uniquement à la démonstration pédagogique.
